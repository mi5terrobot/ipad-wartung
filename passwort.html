Passwort-Code erzeugen

Für die Datei ipads.xlsx, Blatt „Zugang“. Das Passwort selbst wird nirgends gespeichert oder verschickt, die Berechnung passiert nur in diesem Browser.

Den Code in die Spalte „passwort_code“ neben dem Kürzel eintragen, die Datei speichern und als ipads.xlsx ins Repo hochladen.
